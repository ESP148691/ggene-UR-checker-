# Claude Codeへの引き継ぎプロンプト（トップページ 銀河系デザイン 本実装）

以下をそのままClaude Codeのセッションに貼り付けてください。

---

Gジェネエターナル ファンツールの `top.html`（ログイン後トップページ）に、銀河系テーマの動的デザインを本実装してください。デザインの検討・プロトタイプ作成はCowork側で完了済みで、ユーザー承認も得ています。

## 参照ファイル（このリポジトリに追加済み）

作業を始める前に、まず以下2ファイルを読んでください。

- `design-proposal/top-galaxy-prototype.html` — 実際に動くプロトタイプそのもの（ブラウザで直接開いて動作確認できます）。ここに書かれているCSS/JSが実装の元ネタです
- `design-proposal/galaxy-design-proposal.md` — コンセプト、参考事例、配色・タイポグラフィのトークン、動的要素の仕様、パフォーマンス/アクセシビリティ要件、検討の経緯をまとめたドキュメント

## やってほしいこと

1. `top.html` の既存の構造（ログイン導線・機体/サポートチェッカーへのリンク・Coming Soon表示）は維持しつつ、プロトタイプのCSS/JSを移植してください。含まれる主な要素は以下の通りです。
   - 背景：3層の星空パララックス、手続き生成の渦巻銀河（中心コアはエメラルドグリーンベース）、CSSネビュラ、流れ星、スキャンライン・ビネット
   - ロゴ周りのオービットリング、チェッカーカード間のルートライン（点線アニメーション）
   - チェッカー導線カードのアイコンに、フレーム外に滲むエメラルドのオーロラ後光
   - チェッカー導線カードのタイトル文字：シアン⇄ゴールドのグラデーションシマー（白色に戻らない配色ループ）
   - 実装済みチェッカー（機体/サポート）を主役として大きく、Coming Soon（ROUTE 03/04）は脇役として小さく、という表示比重
   - 760px以上の広い画面では2カラムの全幅レイアウト、760px未満（スマホ）は既存同様の1カラムを維持

2. **アイコン画像のランダム表示について**：プロトタイプはデモのため機体6枚・サポート6枚のみをbase64で埋め込んでいますが、本実装では埋め込みをやめて、`images/units/1.jpg`〜`82.jpg`（機体チェッカーのアイコン枠）／`images/supporters/1.jpg`〜`48.jpg`（サポートチェッカーのアイコン枠）への相対パス参照に変更し、対象範囲も全件（82件・48件）からランダム抽出する形にしてください。5秒周期でランダムにフェード切り替える挙動、タブ非アクティブ時の停止、`prefers-reduced-motion`時に初期の1枚で固定する挙動は維持してください。サポート側の画像はキャラクターが右寄りにデザインされているため、プロトタイプ同様に `object-position: 78% center` 相当の右寄りトリミングを適用してください。

3. `auth.css` / `auth.js` によるログイン状態表示（右上のログイン/ユーザー名表示）は変更せず、新しい背景・パネルスタイルに視覚的に馴染む程度の最小限の調整に留めてください。

4. 「今後追加予定」カードの `ROUTE 03` / `ROUTE 04` ラベルは、実際のチェッカー機能が確定した際にそのままカード名表示へ差し替えられるよう、置き換えやすい実装にしてください。

## 必ず守ってほしい制約（既存の確定方針）

- ログイン任意・ゲスト利用維持の方針に影響を与えないこと。今回はあくまで見た目の変更であり、機能導線を塞いだり必須化したりしないこと
- モバイル（特にXアプリ内ブラウザ）での軽量動作を最優先。three.js等の追加ライブラリは使わず、Canvas 2D + 素のJSで完結させること
- `prefers-reduced-motion: reduce` 環境、タブ非アクティブ時のアニメーション停止など、プロトタイプに実装済みのアクセシビリティ/パフォーマンス配慮はすべて引き継ぐこと
- 実装後は既存の運用ルール通り、Playwright等でのヘッドレステスト（表示崩れ・コンソールエラーなし）を行ってから引き渡すこと。特にスマホ幅表示と `prefers-reduced-motion` 有効時の両方を確認すること
- ファイル削除が必要な場合は必ず確認すること

## 未確定・要相談事項

- `unit.html` / `supporter.html` 側にも同じ背景演出を展開するかどうかは、この作業とは別に相談すること（操作系UIでカード枚数が多いため、背景の動きがノイズにならないか要検討）
